# Verify Egypt
Giza Immersion - Egypt ASMR: immersive 3D experience at the Great Pyramid (Next.js 16 + react-three-fiber).
## Launch
npm install, then npm run dev, or npm run build && npx next start.

`python3 .cursor/skills/verify-egypt/verify.py`

Builds the Next.js app, starts the production server, renders the home page in headless Chromium asserting the boot marker and zero JS console errors.
